# Совместимость сохранений Shadow Architect

23 ноября 2026 года. Проверено в одиночном Steam-клиенте Satisfactory 1.2.5.1, CL 520140, SML 3.12.1. Исходный мир содержал две размещённые проекции — «3х3 пустой» (31 объект) и «2 сборщика кабелей» (8 объектов).

| Сценарий | Что сделали в игре | Результат |
|---|---|---|
| Отключение → сохранение → включение | Загрузили копию мира с отключённым Shadow Architect, оставив SML и остальные моды включёнными. Игра записала новый слот. Завершили клиент, включили 0.1.1 и загрузили именно этот слот. | **Обе проекции потеряны в новом слоте.** При отключённом моде в мире было 0 акторов проекции. После повторного включения подсистема запустилась и сообщила `Ready. 0 saved plan(s).` Обе записи Blueprint оставались в библиотеке. |
| Удаление и переименование исходников | Для следующей загрузки той же копии мира убрали из отдельной библиотеки файлы «2 сборщика кабелей» и переименовали пару `.sbp` / `.sbpcfg` чертежа «3х3 пустой» в `QA_renamed_roof`. Игра перечислила ровно один Blueprint под новым именем. | **Обе проекции восстановлены.** Данные обоих планов совпали с контрольными, в мире было два видимых актора проекции. Это проверка уже размещённых планов. |
| Сохранение 0.1.0 → загрузка 0.1.1 | Отдельная установка 0.1.0 загрузила контрольную копию с двумя планами и записала новый слот штатным сохранением игры. В метаданных нового файла проверена запись `ShadowArchitect 0.1.0`. После завершения процесса этот файл открыли в установленной 0.1.1. | **Переход 0.1.0 → 0.1.1 пройден.** До и после обновления в мире была одна подсистема и два видимых актора проекции. Контрольные суммы обеих записей совпали. |

## Что сравнивали

Подготовка чистого клона, пример команды PowerShell и ожидаемые записи журнала собраны в [инструкции фонового прогона](background-testing.md).

Для повторения на отдельной копии мира соберите тестовый плагин `SaveCheck` для той же Steam Shipping-цели, что и мод. Подключите его только к тестовому запуску. Передайте `-SaveCheckRun` для чтения результатов из `LogSaveCheck`. Для штатной записи добавьте `-SaveCheckWrite=SAQ_<новое_имя>`. После чтения или завершения записи плагин закрывает тестовый клиент. Выбор входного слота и версии Shadow Architect задаётся при запуске игры. [Исходники тестового плагина](../tests/compatibility/SaveCheck/)

Каждая загрузка выполнялась в отдельном процессе на копии мира. Тестовый модуль читал массив `Plans` после загрузки, вычислял контрольную сумму текстового представления каждой полной записи и считал акторы `AShadowProjection` с выключенным флагом скрытия. Запись слота проверялась по успешному ответу игры. При загрузке без мода и после обновления использовали разные выходные слоты.

| План | GUID из исходного мира | Контрольная сумма записи |
|---|---|---|
| 3х3 пустой | `396486414CD79819B9C065B066EE5520` | `989bf4d6edaede970ec5bfdef1978b6b` |
| 2 сборщика кабелей | `6E4E9A954896A9D95977ACB5FA91E0E4` | `219900e0f0be81613279571dda0b2fbb` |

В проверке обновления исходные размещения были сделаны в 0.1.1, а проверяемый файл записан настоящей 0.1.0 с этими планами. Обе версии используют схему 1. При изменении структуры сохранения нужно повторить тест с файлом прежней схемы. Видимость здесь проверялась по состоянию акторов в игре, сравнение изображений не проводилось.

## Как сохранить планы при отключении мода

Перед отключением сохраните мир в отдельный слот. Для игры без мода используйте другой слот. После включения загрузите слот, записанный с модом: в прогоне с 0.1.1 именно он сохранил оба плана. Наличие исходных чертежей в библиотеке само по себе не восстанавливает их размещения в мире.
