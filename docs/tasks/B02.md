# B02. Проверить источник перед строительством

**Зависимости** — [B01](B01.md).

## Цель

Реализовать проверку идентичности при выборе источника для строительства.

## С чего начать

Вход — выбранная запись `FShadowPlacement` и библиотека текущего мира. Реализуйте согласованное в B01 правило идентичности. Потребителю требуются проверенный дескриптор либо однозначная причина отказа. [Захват геометрии](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp) · [Данные снимка](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Управление планами](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp)

## Работа

1. Запишите признак источника при создании нового размещения. Для старых записей сохраняйте доступность просмотра и редактирования.
2. При запросе строительства проверьте текущее содержимое библиотеки. Учитывайте удаление или замену файла после выбора плана; повторный запрос должен учитывать изменение.

## Независимая проверка

- [ ] На одном размещении повторите матрицу B01 с исходником, переименованием, удалением и другим содержимым под исходным именем. Сравните фактический статус с решением B01.
- [ ] На старой записи без доказуемого совпадения покажите понятный отказ. После всех отказов тот же GUID остаётся видимым и выбирается; реальных зданий нет.

## Что передать проверяющему

Приложите результаты четырёх случаев и старой записи. Если добавились новые поля сохранения, передайте их ожидаемые значения в Q01.
