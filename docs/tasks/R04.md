# R04. Показать стоимость и остаток для выбранного плана

**Зависимости** — [R02](R02.md), [R03](R03.md), [E02](E02.md).

## Цель

Вывести у края экрана материалы выбранного плана.

## С чего начать

Используйте выбранный GUID из E02, сохранённую стоимость R02 и остатки R03. Источники данных уже принадлежат этим задачам; виджет отвечает за отображение и смену цели. [Управление планами](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Данные снимка](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Исходные пожелания](../roadmap.md)

## Работа

1. Создайте боковую панель локального игрока. Для известной цены покажите по строке на предмет с названием, требуемым и доступным количеством; для неизвестной цены покажите явное состояние.
2. Обновляйте цель при выборе и удалении. Отразите изменение запаса, пока выбран тот же план.

## Независимая проверка

- [ ] Выберите по очереди A и B с разными рецептами. Проверьте исчезновение строк A, подписи и количества B. Уберите ровно один недостающий предмет из полного запаса: дефицит становится различим.
- [ ] Выберите старый план с неизвестной ценой, затем снимите выбор либо удалите цель. Сначала видна подпись, затем панель исчезает. На экране не остаются строки предыдущего плана.

## Что передать проверяющему

Приложите снимки известной цены, нехватки и старого плана. Сверьте числа хотя бы одного снимка с Build Gun и инвентарём.
