# S05. Поставить Blueprint на крышу плана

Для нижнего этажа выберите Blueprint и разместите план клавишей **F7** по умолчанию. Оставьте тот же Blueprint в Build Gun для повторяющихся этажей или выберите другой. Сверху наведитесь на плоскую металлическую крышу или бетонную плиту 8×8×1 м в нижнем плане и откройте **F6 → Place Blueprint on roof**. Действие доступно в представлениях Ghost и Wireframe.

Второй план берёт горизонтальные координаты и угол поворота из нижнего плана. Его нижняя точка совмещается с верхней гранью выбранной детали. Наведение на разные плиты одного перекрытия сохраняет центр этажа. Верхний план становится выбранным. Каждый этаж затем можно двигать и удалять через его меню.

Чтобы построить верхний этаж, откройте **Open build preview** в меню верхнего плана или нажмите Ctrl+Shift+F8 сразу после размещения. ЛКМ использует штатные проверки и подтверждение Build Gun.

## Независимая проверка

- [x] Два экземпляра `3х3 пустой` совмещены по горизонтали и повороту. Основания четырёх верхних колонн касаются бетонного перекрытия нижнего плана. При добавлении второго плана счётчик реальных построек сохраняется.
- [x] Штатное подтверждение верхнего Blueprint проверено, пока нижний этаж остаётся планом. Зафиксированы допуск Build Gun, результат ЛКМ и число созданных построек.

## Результат проверки

23 ноября 2026 года, прогон `RoofStack-final`. Ревизия `3e38d1c` с локальными изменениями S01–S05, Satisfactory Steam CL `520140`, SML `3.12.1`, Shadow Architect `0.1.2`. SHA-256 DLL `226414ec0213fa8dbc92c3404a3d308ea11ecd02f3cb6f1bafab4d152dfaba02`. Входной слот `SAQ_BASE_01`, выходного слота нет. SHA-256 входного слота совпал до и после прогона. Использовалась отдельная копия файлов `3х3 пустой`.

В чертеже 31 объект, в том числе 16 плит перекрытия и четыре двухсекционные колонны. После F7 и команды **Place Blueprint on roof** над нижним перекрытием оба плана имели одинаковые X/Y и поворот 30°. Верхний план оказался на 900 см выше. Зазор у всех четырёх колонн составил 0,00 см. Число реальных объектов при размещении плана осталось 11 719. [Кадр двух призрачных этажей](../../../evidence/S05-stacked-ghosts.jpg)

На верхнем плане **F6 → Open build preview** открыл штатный предпросмотр в сохранённой позе. Build Gun разрешил строительство. Один ЛКМ создал один реальный Blueprint. Все 31 детали совпали по позициям со снимком в пределах 1 см. Нижний этаж оставался призрачным. Стоимость была отключена в памяти тестового мира. [Кадр построенного верхнего этажа](../../../evidence/S05-built-upper.jpg)
