# Привязка к крыше и фундаменту

Откройте меню плана под прицелом и выберите **Show alignment guide**. С выбранным станком доступен **Roof height guide** для плоской металлической крыши или бетонного перекрытия 8×8×1 м. С выбранным фундаментом FICSIT высотой 1 м доступен **Foundation grid guide** для такой же детали в плане. С выбранным Blueprint пункт **Place Blueprint on roof** ставит его план вторым этажом на плоское перекрытие. Build Gun проверяет настоящую постройку. [Исследование запроса Build Gun](02-test-hologram-surface.md)
