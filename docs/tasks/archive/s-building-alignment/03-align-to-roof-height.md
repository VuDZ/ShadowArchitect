# S03. Дать ориентир высоты по крыше

**Зависимости** — [S02](02-test-hologram-surface.md).

## Цель

Дать ориентир высоты для станка на выбранной крыше поддерживаемого типа.

## С чего начать

Исходные данные — измерения S01 и решение S02 по крыше. Начните с плоской поверхности конкретного поддержанного типа. Для уклона высота зависит от точки попадания. [Рендер проекции](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowProjection.cpp) · [Управление планами](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Исходные пожелания](../../../roadmap.md)

## Работа

1. Используйте выбранную в S02 поверхность или визуальную направляющую. Определяйте высоту по действительной грани выбранной крыши в мировых координатах.
2. Проверьте скат как отдельный случай. Когда доступен только габарит детали, укажите ограничение для наклонной поверхности. Штатная проверка допустимости остаётся у Build Gun.

## Независимая проверка

- [x] На повёрнутой плоской крыше сравните высоту и направление станка с эталоном на настоящей крыше. Переместите сам план выше и повторите: ориентир следует за крышей.
- [x] Для ската наведите прицел в две точки разной высоты. Результат следует уклону либо тип явно отмечен как неподдержанный. Для визуального режима проверяющий должен видеть, что разрешение постройки выдаёт игра.

## Что передать проверяющему

Укажите поддержанные типы, способ работы и измеренное отклонение от эталона. Приложите один удачный и один ограничивающий случай.

## Режим Roof height guide

Откройте F6 над планом и выберите **Show alignment guide**. С выбранным в Build Gun станком наведитесь сверху на плоскую металлическую крышу `Build_Roof_A_01`. Ориентир отмечает высоту грани и два направления в осях детали. Он строится по коллизионной геометрии `SM_Roof_Steel_01` в текущей мировой позе детали. Скатные крыши показывают сообщение **This roof is unsupported. Use a flat metal roof.** Голограмма станка и разрешение постройки остаются под управлением Build Gun. [Код ориентира](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowAlignmentGuide.cpp)

## Результат проверки

23 ноября 2026 года, `S03-S04-final`. Ревизия `3e38d1c` с изменениями S01–S04, Satisfactory Steam CL `520140`, SML `3.12.1`, Shadow Architect `0.1.2`. SHA-256 DLL мода `3ba1a4280b5a204d55ca8ad3c17a7d6f2113f5818e854d79a6c6d06ee62705f9`. Входной слот `SAQ_BASE_01`, записей в выходной слот не было. SHA-256 входного слота совпал до и после прогона.

Ожидались высота и направление штатного предпросмотра Foundry на настоящей крыше. Измерили Z = 10384,02 см и поворот 30°. Ориентир на призрачной крыше дал те же значения с точностью журнала 0,01 см и 0,01°. После подъёма плана на 500 см ориентир поднялся до 10884,02 см. В обоих положениях опорная грань была на 41,00 см выше начала детали. На проекции Build Gun по-прежнему сообщал `Invalid aim location!`. [Плоская крыша](../../../evidence/S03-roof.jpg) · [После подъёма](../../../evidence/S03-roof-raised.jpg)

На `Build_Roof_A_04` при локальном X = +230 и −230 см появилось предупреждение о неподдерживаемом скате. Линий высоты в обоих случаях не было. В S01 высоты попаданий на реальной детали в этих точках различались на 230 см. [Кадр скатной крыши](../../../evidence/S03-slope.jpg) · [Эталон S01](01-measure-native-snapping.md)

