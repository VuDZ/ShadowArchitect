# K01. Переназначить размещение плана через настройки игры

**Зависимость** — [V03](../v-display-modes/03-switch-display-mode.md). **Цель** — игрок меняет клавишу «Разместить план» в штатном меню управления и сразу пользуется ею в мире.

## С чего начать

В `AShadowPlanSubsystem::BindControls` найдите связь между F7 и `Place`. Для Satisfactory 1.2 / SML 3.12 используйте переназначаемый Input Action, дочерний контекст `FGChildInputMappingContext` и его регистрацию через Game Feature Data. Сверьте с ExampleMod из установленного SDK. [Текущий обработчик](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Изменения Enhanced Input в SML 3.12](https://docs.ficsit.app/satisfactory-modding/latest/Development/UpdatingFromSml311.html#_enhanced_input)

## Работа

1. Выведите одно действие в группе Shadow Architect с начальной клавишей F7 и стабильным идентификатором. Направьте ввод в существующий `Place`. Уберите прежнюю прямую подписку для этого действия. Сохраните команду чата `/shadowplace`.
2. Подберите контекст и обработку сочетаний с учётом обычного Q, Build Gun и ввода в чат. Остальные пять действий переносятся в K02.

## Независимая проверка

- [x] Установите собранный ZIP в отдельный профиль с исходными настройками. Вызовите предпросмотр Blueprint. Одно нажатие F7 добавляет один GUID. В меню управления назначьте Ctrl+Q, примените и вернитесь в мир.
- [x] С убранным Build Gun нажмите Q — открывается обычное меню строительства. С активным предпросмотром нажмите Ctrl+Q — появился ровно один новый GUID, меню строительства не открылось. F7 больше не добавляет план. Повторите после перезапуска клиента.
- [x] Введите текст в чат, затем выполните `/shadowplace` с убранным Build Gun. Набор текста не меняет мир, команда возвращает штатную подсказку. Сбросьте назначение в настройках и проверьте размещение по F7.

Передайте кадр назначения, число планов до и после каждого действия и SHA-256 установленной DLL из ZIP. Если клиент отклоняет сочетание или одновременно открывает строительство, запишите фактическое поведение и состояние Build Gun. Оставьте этот критерий открытым и укажите проверенную одиночную клавишу для сравнения.

## Результат проверки

23 ноября 2026 года. `f8d5818` с изменениями K, Satisfactory Steam CL `520140` (ветка сборки `rel-main-1.2.6`), SML `3.12.1`, Shadow Architect `0.1.2`. SHA-256 установленной DLL и DLL из ZIP `d7655aa1399261a6335abf947a30c7d161b265e0f07b496f94593471255c5599`. Входной слот `SAQ_BASE_01`. Выходной слот не записывался.

- Чистый профиль, активный предпросмотр. F7 увеличила число планов с 2 до 3. Новый GUID `F4CC61414F511220D1AA3996D5883C8F`.
- В отдельном слоте `SAQ_K_UI_01` открыли **Options → Keybindings → Shadow Architect**. В группе видны семь действий. После выбора строки **Place plan** и ввода Ctrl+Q значение сразу сменилось с `F7` на `Left Ctrl + Q`. Назначение записалось в профиль, выходной слот не создавался. [Кадр назначения](../../../evidence/K01-placement-ctrl-q.jpg)
- При автоматическом повторении переназначения через API управления Q с убранным Build Gun открыла меню строительства, осталось 2 плана. С активным предпросмотром F7 оставила 2 плана, Ctrl+Q добавила один план `29E2B4DB4422841C7358D1B0F1D52C77`. Меню строительства оставалось закрытым.
- После перезапуска того же профиля наблюдалась та же последовательность. Q открыла меню, F7 оставила 2 плана. Ctrl+Q добавила GUID `151D728F4E2E0023E004B0A3DFBAE073`, стало 3 плана.
- В поле чата введена `q` и нажата Ctrl+Q с активным предпросмотром. Осталось 3 плана. С убранным Build Gun команда `/shadowplace` ответила `Select a blueprint with the Build Gun first.`, осталось 3 плана.
- Профиль с назначением из видимого меню после перезапуска показывал Ctrl+Q. Штатный сброс вернул F7. С предпросмотром F7 добавила GUID `8843A1FC468A84099DA1CABD9F0A8109`, число планов выросло с 2 до 3.
- Повтор на итоговой DLL `fe70c7db0492bb159d87a1ad45e4d16051d160d0b59aee8da0a31a807eee3144` после доработки меню плана. Обычная Q открыла меню строительства, Ctrl+Q с активным Build Gun добавила только `F8F4186F4051F198F7C82EBA7CB84A85` (2 → 3) и оставила меню закрытым. Чат и `/shadowplace` повторили прежний результат.

```text
input=Q build_menu_cursor=1
action=old F7 mode=Ghost plans=2
input=Ctrl+Q build_menu_cursor=0
action=Ctrl+Q with Blueprint preview mode=Ghost plans=3
chat focus=SEditableText typed=q
pass=1 rebound placement and chat
```
