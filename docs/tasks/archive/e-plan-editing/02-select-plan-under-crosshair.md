# E02. Выбрать проекцию под прицелом

**Зависимости** — [E01](01-check-editing-controls.md).

## Цель

Добавить выбор проекции под прицелом.

## С чего начать

Проекции имеют `NoCollision`. Источники данных — сохранённые габариты `Parts`, `Plan.Transform` и соответствие GUID → актор в `Views`. Результатом выбора служит существующее поле `Selected`. [Управление планами](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Данные снимка](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Рендер проекции](../../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowProjection.cpp)

## Работа

1. Получите луч камеры локального игрока при явном действии выбора. Ограничьте его первым непрозрачным препятствием мира.
2. Найдите ближайшее положительное пересечение с видимой проекцией. Подход без игровой коллизии — проверить луч в локальных осях габаритов деталей, затем сравнить расстояния в мире.
3. Передайте GUID в существующую логику выбора, выведите его для проверки. Оставьте доступным обход через J. Опишите действие выбора и поведение при промахе.

## Независимая проверка

- [x] Расположите A перед B на одном луче и направьте прицел на общую часть. Действие выбирает A. Обойдите пару с обратной стороны — выбирается B.
- [x] Поставьте непрозрачную стену между камерой и обоими планами, затем скройте планы и повторите без стены. В обоих случаях команда не выбирает закрытую цель. Наведение и промах сохраняют размещения.

## Что передать проверяющему

Приложите положение камеры в трёх опытах и возвращённый GUID либо признак промаха. Подсветку выполняет E03. [Результат проверки](verification.md#e02-выбор-под-прицелом)
