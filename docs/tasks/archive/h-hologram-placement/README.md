# Размещение чертежа на голограмме

На настоящем фундаменте стоит призрачная площадка на колоннах. Игрок выбирает «3 литейных» и хочет разместить их у левого или правого края перекрытия. До подтверждения должно быть видно, на что опираются литейные, что им мешает и какую клавишу нажать.

Реализовано в Shadow Architect 0.3.0. [Игровые замеры, кадры и открытые проверки](verification.md)

| Задача | Результат для игрока | С чего начать |
|---|---|---|
| [H01. Выбрать опору под прицелом](01-snap-to-aimed-hologram.md) | Переключатель разрешает ставить план прямо на верхнюю грань видимой голограммы. | Доступна отдельно. |
| [H02. Увидеть пересечения до размещения](02-highlight-plan-conflicts.md) | Цвет активного чертежа, контуры деталей и текст объясняют, свободно ли место. | Детектор можно проверять отдельно. Итоговый сценарий использует H01. |
| [H03. Видеть действующие клавиши сбоку](03-show-contextual-building-controls.md) | Панель показывает команды текущего действия и выбранный режим опоры. | Использует действие переключения из H01. |
| [H04. Пользоваться меню плана при открытом Build Gun](04-fix-plan-menu-input-and-layering.md) | Все кнопки читаются, наведение заметно, результат нажатия виден. | Доступна отдельно. |

## Сцена для приёмки

В отдельной копии мира разместите план площадки на колоннах над настоящим полом. Подойдут «3х3 пустой» с плоским перекрытием и верхний Blueprint «3 литейных» либо равнозначные копии. Оставьте на полу точку, куда можно навестись мимо площадки. Для проверки конфликта поставьте второй план с колонной, выступающей над перекрытием в зоне одной из литейных. Зафиксируйте исходные GUID планов, число реальных зданий и материалы. Каждую карточку начинайте с известного состояния сцены.

Команда [«Поставить Blueprint на крышу»](../s-building-alignment/05-stack-blueprint-on-roof.md) уже совмещает этажи по центру нижнего плана. Для H01 положение верхнего чертежа задаёт сам игрок прицелом до фиксации. Все четыре задачи можно проверять с командой разового размещения плана (по умолчанию F7) в текущем Build Gun.
