# H02. Увидеть пересечение планов до размещения

**Цель.** Пока игрок двигает «3 литейных», **текущий Blueprint** зелёный в свободном положении. При наложении он меняет цвет, а игрок видит, какая литейная задевает какую деталь соседнего плана.

Проверяйте геометрию в фактически показанной позе с учётом поворота. Используйте общий габарит для отбора кандидатов и габариты отдельных деталей для уточнения. Простое касание опорной грани допустимо. Если доступен только грубый габарит и точное пересечение установить нельзя, покажите «Возможное пересечение». Состояние свободного места сопровождайте текстом «Свободно», подтверждённый конфликт — контрастным цветом и именем затронутого плана. При конфликте выделяйте обе участвующие детали. Сохраняйте штатные предупреждения и запреты Build Gun для настоящих объектов, в том числе когда планы между собой не пересекаются. Предупреждение мода о наложении двух планов допускает намеренное размещение. ## Независимая проверка

- [ ] В [сцене с литейными](README.md#сцена-для-приёмки) поставьте предпросмотр подошвами на плиту в свободном месте. Текущий Blueprint зелёный, видна надпись «Свободно», площадка сохраняет собственное оформление. Проверьте касание стыка плит и свободный промежуток между колоннами внутри общего габарита нижнего плана.
- [ ] Сдвиньте одну литейную в выступающую колонну второго плана и поверните предпросмотр. Пока объёмы пересекаются, видно имя плана, выделены колонна и конкретная литейная. При выходе из пересечения зелёный цвет возвращается сразу. Наведение и поворот сами по себе не добавляют планов.
- [ ] Зафиксируйте заведомое наложение командой размещения призрака. Создан один план, реальные здания и ресурсы прежние. Отдельно наведите чертёж на реальное здание с известным запретом Build Gun. Состояние «Свободно» исчезает, штатный запрет остаётся. Проверьте это также при выключенной привязке к планам.

Передайте сопоставимые кадры свободного места, касания, пересечения и штатного запрета. Итоговую проверку положения на плите повторите с [H01](01-snap-to-aimed-hologram.md).
