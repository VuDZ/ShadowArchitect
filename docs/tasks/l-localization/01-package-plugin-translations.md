# L01. Загрузить перевод из установочного архива

**Цель.** На одной существующей кнопке доказать, что Steam-клиент загружает перевод Shadow Architect согласно языку игры.

Создайте в Localization Dashboard цель типа **Plugin Target** для ShadowArchitect. Настройте сбор текста из C++ и ассетов самого плагина, английский исходный язык и русский перевод. Начните с ключа кнопки Move. Соберите текст, скомпилируйте ресурсы локализации и упакуйте мод обычным для проекта способом. Зафиксируйте файлы и настройки, необходимые для повторной сборки из чистого клона. [Меню плана](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlanMenu.cpp) · [Дескриптор плагина](../../../src/ShadowArchitect/ShadowArchitect.uplugin) · [Руководство по локализации](https://docs.ficsit.app/satisfactory-modding/latest/Development/Localization.html)

## Независимая проверка

- [ ] Установите ZIP в отдельный профиль без исходников и редакторских ресурсов. Выберите русский в самой игре, откройте меню плана и найдите «Переместить».
- [ ] В том же профиле смените язык игры на английский штатным способом и примените настройку. Откройте то же меню — видно «Move». Если сама игра требует перезапуска, повторите после него. Отдельно укажите, на каком шаге сменился язык мода.
- [ ] Передайте ревизию, SHA-256 архива, расположение скомпилированных ресурсов внутри сборки и два кадра одной кнопки. Если перевод отсутствует, проверьте сбор ключа, упаковку и загрузку ресурсов до вывода об ограничении автоматического выбора.
