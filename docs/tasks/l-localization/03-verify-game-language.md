# L03. Выпустить и проверить первый комплект переводов

**Цель.** Проверить русский и исходный английский на одном публичном ZIP. Для языка игры без перевода должен читаться английский текст. Зависимости — [L01](01-package-plugin-translations.md) и [L02](02-cover-player-facing-text.md).

Заполните русский каталог для всей инвентаризации L02 и проверьте его после последнего сбора строк. Проверьте единообразие терминов «план», «чертёж», «голограмма», длину кнопок и русские числительные в реальных фразах. В README укажите языки выпуска и когда игра применяет смену языка.

## Независимая проверка

- [ ] В одном тестовом мире пройдите русскую и английскую версии одного сценария: загрузка мира, список назначений, меню F6, выбор плана, отображение ориентира, очистка с отменой, уведомление об успехе и отказ при строительстве. Сверьте остальные поверхности с инвентаризацией L02. Все предусмотренные переводы видны, кнопки читаются полностью. Зафиксируйте исходный и итоговый GUID и имя чертежа.
- [ ] В форме со счётчиком проверьте 1, 2 и 5 планов. Установите язык игры, для которого мод пока не поставляет перевод. В тех же меню и сообщениях появился английский текст. Нет пустых подписей, внутренних ключей и неподставленных параметров.
- [ ] Верните русский язык и перезапустите клиент. Повторите на неизменном архиве, запишите версии игры и мода, выбранный в игре язык, кадры и результат по каждой поверхности. Для каждого видимого исключения укажите конкретную строку и причину. Решение о необходимости ручного выбора привяжите к этим результатам.
