# Язык интерфейса Shadow Architect

Игрок запускает Satisfactory на русском и видит «Переместить» в меню плана. При английском интерфейсе в том же месте появляется «Move». Имя собственного чертежа, например «Цех №2», сохраняется в обоих случаях.

| Задача | Что получит игрок | Зависимость |
|---|---|---|
| [L01. Загрузить перевод из установочного архива](01-package-plugin-translations.md) | Одна поставка мода для игроков с разными языками игры. | Можно начать сразу. |
| [L02. Подготовить все видимые тексты к переводу](02-cover-player-facing-text.md) | Меню, список клавиш, подсказки, сообщения и отказы используют единый каталог. | Можно начать с инвентаризации параллельно с L01. Для проверки нужен L01. |
| [L03. Выпустить и проверить первый комплект переводов](03-verify-game-language.md) | Русский и английский в игре, понятный текст при отсутствии перевода. | L01 и L02. |
| [L04. Выбирать язык через меню Mods при необходимости](04-select-mod-language.md) | Локальный выбор языка мода, если в Shipping подтверждено ограничение автоматического режима. | По результатам L01/L03. |

Для следующих функций, включая подсветку пересечений и боковую панель управления, включайте новые надписи в тот же каталог. Другие языки можно добавлять по мере готовности переводов.
