# L04. Выбирать язык Shadow Architect через Mods при необходимости

**Условие начала.** Если [L01](01-package-plugin-translations.md) и [L03](03-verify-game-language.md) подтвердили автоматический выбор языка во всех нужных местах, достаточно записать этот результат. Если подтвердилось ограничение механизма выбора, укажите его и реализуйте запасной вариант.

**Цель.** Игрок открывает в главном меню **Mods → Shadow Architect** и выбирает «Язык игры», «Русский» или «English». По умолчанию используется язык игры, а список явных вариантов соответствует реально поставляемым каталогам. Используйте локальные настройки мода SML. Проверьте механизм выбора перевода именно для этого плагина, включая уже открытые экраны и подписи действий ввода. Опишите момент применения в интерфейсе, если требуется переоткрытие меню или перезапуск. [Настройки модов в SML](https://docs.ficsit.app/satisfactory-modding/latest/ForUsers/ConfiguringMods.html)

## Независимая проверка запасного варианта

- [ ] При английской игре выберите «Русский» на странице мода. Откройте мир, проверьте меню F6, строку назначения клавиши и новый ответ в чате. В тексте Shadow Architect виден русский, основной интерфейс игры сохраняет английский.
- [ ] Перезапустите клиент, откройте другой мир и проверьте выбранный язык. Затем выберите «Язык игры»: после применения тексты мода следуют текущему языку Satisfactory. Настройка локальна для установки или профиля и не записывается в сохранение мира.
- [ ] Проверьте возможность вернуться в автоматический режим при неизвестном или удалённом коде языка. Передайте кадр страницы Mods, проверенные поверхности и фактический момент применения.
