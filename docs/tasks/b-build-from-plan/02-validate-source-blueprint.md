# B02. Проверить источник перед строительством

**Зависимости** — [B01](01-identify-source-blueprint.md).

## Цель

Реализовать проверку идентичности при выборе источника для строительства.

## С чего начать

Вход — выбранная запись `FShadowPlacement` и библиотека текущего мира. Реализуйте согласованное в B01 правило идентичности. Потребителю требуются проверенный дескриптор либо однозначная причина отказа. [Захват геометрии](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp) · [Данные снимка](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Управление планами](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp)

## Работа

1. Запишите признак источника при создании нового размещения. Для старых записей сохраняйте доступность просмотра и редактирования.
2. При запросе строительства проверьте текущее содержимое библиотеки. Учитывайте удаление или замену файла после выбора плана; повторный запрос должен учитывать изменение.

## Реализация

Штатный загрузчик Blueprint отдаёт точные байты, из которых создаётся предпросмотр. Мод сохраняет отпечаток этих байтов вместе с размещением. Если файл заменили после открытия предпросмотра и до F7, план сохраняет отпечаток открытого источника. При отсутствии подтверждённого чтения сохраняется пустая строка.

При запросе строительства библиотека перечитывается с диска. После единственного совпадения по отпечатку мод обновляет библиотеку игры, проверяет актуальный дескриптор и повторяет чтение через штатный загрузчик по его имени. Габариты и стоимость дескриптора обновляются из текущего заголовка. Действие возвращает проверенный источник или сообщение с причиной отказа.

Поле `BlueprintSourceProof` добавлено в запись схемы 1. Для [Q01](../q-save-compatibility/01-load-older-save.md) ожидается пустая строка у прежних записей и точная строка формата `blake3-sbp-v1:<64 строчных шестнадцатеричных символа>` у нового размещения, захваченного после штатного чтения. Повторное открытие сохранения должно возвращать то же значение.

## Независимая проверка

- [x] На одном размещении повторите матрицу B01 с исходником, переименованием, удалением и другим содержимым под исходным именем. Сравните фактический статус с решением B01.
- [x] На старой записи без доказуемого совпадения покажите понятный отказ. После всех отказов тот же GUID остаётся видимым и выбирается; реальных зданий нет.

## Игровой прогон

23 ноября 2026 года. Рабочие изменения после B01 `644fd91`, Satisfactory Steam Shipping `rel-main-1.2.6`, CL `520140`, SML `3.12.1`, Shadow Architect `0.1.2`. Входной тестовый слот `SAQ_BASE_01`, библиотека с `QA_A` из B01. SaveCheck открыл штатный Blueprint, зафиксировал тестовую позу в предпросмотре, нажал F7 и записал новый слот `SAQ_B02_SOURCE_01`. Отпечаток нового плана совпал с измеренным в B01.

```text
Placed QA_A [403D6FE449B5CC9E91C3F8B2937FE501], 8 objects.
seed=SAQ_B02_SOURCE_01 id=403D6FE449B5CC9E91C3F8B2937FE501 digest=blake3-sbp-v1:971cc42d49480aadd0820ebfee8d07f77cfd66e5c6db800a4cafa553481b8fb1
pass=1 write source seed
```

Затем каждый случай матрицы B01 загрузили из `SAQ_B02_SOURCE_01` с отдельной библиотекой. SaveCheck выбрал размещение клавишами Ctrl+Shift+J и запросил строительство через Ctrl+Shift+F8. Для `QA_A` и `QA_A_renamed` открылся предпросмотр с соответствующим дескриптором. При удалении, подмене и двух одинаковых копиях мод вернул соответствующую причину отказа. Во всех этих отказах GUID `403D6FE449B5CC9E91C3F8B2937FE501` остался видимым и выбираемым, число зданий и запас не изменились.

Прежнюю запись `396486414CD79819B9C065B066EE5520` выбрали из `SAQ_BASE_01`. Отпечаток был пуст, мод предложил заново разместить план из Blueprint, проекция осталась видимой. В этой проверке было 11 729 зданий и 449 групп Blueprint до и после запроса, инвентарь не менялся. Матрица и проверка старой записи выполнялись без записи выходных слотов.

```text
found:QA_A          preview=QA_A         visible=1
found:QA_A_renamed  preview=QA_A_renamed visible=1
missing             preview=none         visible=1 unchanged=1 pass=1
replaced            preview=none         visible=1 unchanged=1 pass=1
duplicate           preview=none         visible=1 unchanged=1 pass=1
legacy              preview=none         visible=1 unchanged=1 pass=1

The Blueprint source is missing.
The Blueprint source has changed.
The Blueprint source is ambiguous. Multiple library files have the same contents.
This plan has no verifiable Blueprint source. Place a new plan from the Blueprint.
```

Дополнительный прогон на сборке B04 загрузил `SAQ_B02_SOURCE_01`. После первого успешного Ctrl+Shift+F8 SaveCheck закрыл предпросмотр, подменил `QA_A.sbp` в одноразовой библиотеке и нажал то же сочетание без повторного выбора. У выбранного GUID осталась видимая проекция. В пределах плана и 800 см вокруг него сохранились 24 здания, в мире осталось 449 групп Blueprint с 4285 деталями. Запас материалов сохранился. Выходной слот не записывался. [Запуск SaveCheck](../../background-testing.md#b02b04-строительство-по-плану)

```text
source_live_replaced=1 id=403D6FE449B5CC9E91C3F8B2937FE501 preview=QA_A
The Blueprint source has changed.
source_case=live-replaced ... near_plan=24->24 proxies=449->449 parts=4285->4285 inventory_same=1 plan_same=1
source_case=live-replaced ... preview=none visible=1 unchanged=1 pass=1
```

## Что передать проверяющему

Приложите результаты четырёх случаев и старой записи. Если добавились новые поля сохранения, передайте их ожидаемые значения в Q01.
