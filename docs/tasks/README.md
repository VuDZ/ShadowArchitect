# Задачи Shadow Architect

Здесь собраны открытые задачи и повторяемые проверки. В каждой папке есть описание функции, список задач и условия их проверки. Номер в имени файла совпадает с номером в карточке. Например, P02 — вторая задача раздела о режиме планирования.
