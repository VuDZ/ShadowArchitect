# R03. Узнать доступный запас строительных материалов

**Зависимости** — [R01](01-calculate-blueprint-cost.md).

## Цель

Вычислять, сколько каждого нужного материала доступно для строительства сейчас.

## С чего начать

R01 выдаёт перечень необходимых предметов. Здесь нужен остаток, доступный конкретному локальному игроку по правилам Build Gun в момент запроса. [Управление планами](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Исходные пожелания](../../roadmap.md)

## Работа

1. Найдите в SDK путь, которым игра проверяет возможность оплатить обычную постройку. Проверьте источники инвентаря и правила пользования дименсиональным хранилищем.
2. Для запрошенных типов предметов верните доступные количества. Отделите выбор источников от отображения и сверяйте поведение с реальной постройкой на копии мира.

## Независимая проверка

- [ ] Для материала с ценой N проверьте N единиц и N−1 при достаточном запасе остальных. Возврат и отказ/разрешение Build Gun должны согласоваться.
- [ ] Переложите материал так, чтобы он был только в хранилище. Для доступных вариантов настройки запишите ожидаемый и фактический результат; изменение приоритета расходования само по себе может сохранять доступную сумму. Верните часть в инвентарь и проверьте обновление без двойного учёта.

## Что передать проверяющему

Приложите таблицу «в инвентаре / в хранилище / настройка / доступно / результат игры». Для замера используйте обычный режим с расходом ресурсов.
