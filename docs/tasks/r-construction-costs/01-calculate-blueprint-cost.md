# R01. Рассчитать цену целого Blueprint

**Зависимости** — можно начинать с 0.1.1.

## Цель

Получить список материалов целого Blueprint при захвате и агрегировать одинаковые предметы.

## С чего начать

Во время `CaptureBlueprint` доступны дескриптор и временные здания предпросмотра. В SDK есть `AFGBlueprintSubsystem::CalculateBlueprintCost`; проверьте, какой источник цены даёт тот же результат, что активный Build Gun. [Захват геометрии](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp) · [Данные снимка](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Исходные пожелания](../../roadmap.md)

## Работа

1. Снимайте цену, пока доступен проверенный исходник. Приводите количество к единицам игрового предмета, одинаковые предметы суммируйте по устойчивому идентификатору.
2. Передавайте результат как известный список либо как неизвестную стоимость. В этой задаче достаточно получить и показать данные для сравнения в тестовом выводе.

## Независимая проверка

- [ ] Возьмите чертёж одного станка и второго чертежа с двумя одинаковыми станками и фундаментом. Для каждого выпишите пары предмет/количество из Build Gun и сопоставьте все строки с результатом.
- [ ] Проверьте вход с известным пустым списком и случай отсутствующего источника стоимости. Первый даёт известный ноль, второй — «неизвестно». Отсутствующий предмет и повторяющиеся строки видны при построчной сверке.

## Что передать проверяющему

Приложите обе таблицы сравнения и выбранный источник цены. Запись стоимости в save и боковую панель выполняют R02 и R04.
