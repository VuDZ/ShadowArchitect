# P02. Ввести режим планирования и индикатор

**Зависимости** — [P01](01-check-build-interception.md), при подтверждённом перехвате, и [K01](../k-controls-and-menu/01-rebind-plan-placement.md).

## Цель

Включать и выключать режим планирования. Кандидат на клавишу — F8, привязка переназначается при конфликте.

## С чего начать

Начинайте после доказанного в P01 способа остановить обычную постройку. Состояние режима относится к локальному игровому сеансу. Показ уже размещённых планов управляется отдельно. [Управление планами](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Данные снимка](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h) · [Сборка и управление](../../../README.md)

## Работа

1. Добавьте действие «Включить/выключить планирование» в группу Shadow Architect штатного меню управления по образцу K01. Проверьте F8 как начальное назначение. Добавьте однозначный экранный индикатор.
2. В активном режиме подключите точку из P01. Пока тип не поддержан, поглотите подтверждение и покажите причину. При выходе восстановите штатную обработку.

## Независимая проверка

- [ ] Включите режим, выберите неподдержанный тип и подтвердите. Есть индикатор и причина отказа, новых зданий нет, инвентарь прежний. Повторите после смены предмета в Build Gun.
- [ ] Выключите режим. Индикатор исчезает, один обычный клик строит один фундамент по цене игры. Отдельно выберите Blueprint и нажмите действующую клавишу разового размещения — появляется один план.
- [ ] Через меню управления назначьте планированию другую свободную клавишу. Она включает и выключает индикатор после перезапуска. Прежняя клавиша больше не переключает режим. Вид существующих планов (Ghost, Wireframe или Footprint) сохраняется при обоих переключениях.

## Что передать проверяющему

Приложите запись обоих переключений и дельт инвентаря. Если P01 не нашёл рабочего перехвата, отметьте блокирующий вывод в карточке вместо выпуска частично работающего режима.
