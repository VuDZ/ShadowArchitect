# B03. Открыть строительный предпросмотр на месте плана

**Зависимости** — [B02](B02.md), [E02](E02.md).

## Цель

Открыть штатный предпросмотр в позиции и ориентации выбранного призрака.

## С чего начать

Выбранный GUID даёт `Plan.Transform`, B02 возвращает проверенный источник. `ActivePreview` читает уже существующий preview; для открытия и позиционирования найдите штатный путь Build Gun в SDK. [Управление планами](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Захват геометрии](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp) · [Данные снимка](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h)

## Работа

1. Откройте предпросмотр целого исходного чертежа и совместите его якорь с позой выбранного размещения. Учтите смещение pivot у асимметричного чертежа.
2. Проверьте состояние после следующего обновления Build Gun. Открытие, отмена и отказ источника завершаются без расхода и без добавления реальных зданий.

## Независимая проверка

- [ ] Выберите по очереди две копии на разных высотах и с разницей поворота 90°. Сверьте якорь и положение двух удалённых деталей у каждой; совпадение лишь центра габаритов недостаточно.
- [ ] Откройте, отмените, повторите для другой цели. Число проекций, количество реальных зданий и ресурсы прежние. При отказе B02 не открывается preview другого чертежа.

## Что передать проверяющему

Приложите сравнение поз после обновления preview и замер до/после отмены. Само подтверждение постройки относится к B04.
