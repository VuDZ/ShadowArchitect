# K04. Показывать игроку действующую клавишу

**Зависимость** — [K02](02-rebind-plan-actions.md). **Цель** — подсказка по размещению и инструкция ведут игрока к текущему назначению.

## Работа

Начните с формирования `PlaceHint` в `BindControls`. При формировании каждой игровой подсказки о клавише запрашивайте действующее назначение у локального игрока по идентификатору действия. Если размещению не назначена клавиша, укажите `/shadowplace` или путь в настройки. В README опишите переназначение в игре, исходные назначения и сброс. Сохраните раздел о формате старого INI для миграции K03. [Подсказка при загрузке](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Управление](../../../README.md#управление)

## Независимая проверка

- [ ] На чистом профиле загрузите мир и сверьте клавишу в сообщении с меню. Назначьте размещению другое поддерживаемое сочетание и заново загрузите мир. В новом сообщении видны основная клавиша и все назначенные модификаторы. Создайте один план по этой подсказке.
- [ ] Снимите назначение и вновь загрузите мир. Подсказка остаётся выполнимой, прежняя клавиша исчезла из сообщения. Вызовите предложенную команду или верните назначение через указанный раздел меню.

Передайте три текста подсказки и соответствующие им назначения. Ранее выведенные строки истории чата переписывать не требуется.
