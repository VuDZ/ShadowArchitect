# K02. Перенести остальные пять действий в настройки

**Зависимость** — [K01](01-rebind-plan-placement.md). **Цель** — игрок переназначает каждое из шести существующих действий Shadow Architect через одну группу настроек.

## Работа

По образцу «Разместить план» добавьте пять действий со стабильными идентификаторами. Подключите существующие обработчики, сохранив их исходные назначения для чистого профиля. Уберите соответствующие прямые подписки в `BindControls`. [Обработчики и старые привязки](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Исходная раскладка](../../../README.md#управление)

| Действие | Проверяемый результат одного нажатия |
|---|---|
| Выбрать следующий план | При двух планах выбранный GUID сменился с A на B. |
| Переместить выбранный план | С активным предпросмотром поза B совпала с его позой, A остался на месте. |
| Удалить выбранный план | В конце сценария удалён B, остался A. |
| Скрыть/показать планы | Одно нажатие скрывает оба плана, повторное возвращает их. |
| Сменить вид планов | Одно нажатие переводит оба плана ровно на одну позицию в цикле V03. |

## Независимая проверка

- [x] В чистом профиле видны шесть разных строк группы. Разместите два плана. Проверьте исходные клавиши по таблице, удаление выполните последним.
- [x] Через меню назначьте пяти действиям разные свободные клавиши и перезапустите игру. На двух планах повторите таблицу новыми клавишами. Для каждой прежней клавиши проверьте, что она больше не вызывает соответствующее действие мода.
- [x] С открытым чатом и в настройках нажмите новую клавишу удаления при выбранном плане. После закрытия интерфейса оба GUID на месте.

Передайте таблицу прежних и новых клавиш с результатом каждого действия и кадр шести строк в настройках.

## Результат проверки

23 ноября 2026 года. Ревизия `f8d5818` с изменениями K, Satisfactory Steam CL `520140` (ветка сборки `rel-main-1.2.6`), SML `3.12.1`, Shadow Architect `0.1.2`. Входной тестовый слот `SAQ_BASE_01`, выходной слот не создавался. В штатном меню видны все шесть действий и отдельная строка открытия меню плана. [Кадр исходных назначений](../../evidence/K02-keybindings-default.jpg)

В чистом профиле выбраны A `396486414CD79819B9C065B066EE5520` и затем B `6E4E9A954896A9D95977ACB5FA91E0E4`. SaveCheck проверил исходную раскладку в сборке с SHA-256 DLL `d7655aa1399261a6335abf947a30c7d161b265e0f07b496f94593471255c5599`, сохранил пять новых сочетаний через штатный API и перечитал их после перезапуска. Переназначенная раскладка прошла сценарий в итоговой сборке с SHA-256 DLL `fe70c7db0492bb159d87a1ad45e4d16051d160d0b59aee8da0a31a807eee3144`.

| Действие | Исходная клавиша | Новая клавиша и наблюдение после перезапуска |
|---|---|---|
| Выбрать следующий план | Ctrl+Shift+J | Ctrl+Shift+F2, по одному переходу на A и B |
| Переместить выбранный план | Ctrl+Shift+M | Ctrl+Shift+F3, B совпал с предпросмотром `(-234200, -104600, 5400)` см, поза A прежняя |
| Удалить выбранный план | Ctrl+Shift+K | Ctrl+Shift+F4, удалён B, остался A |
| Скрыть/показать планы | Ctrl+Shift+V | Ctrl+Shift+F5, число видимых изменилось `2 → 0 → 2` |
| Сменить вид планов | Ctrl+Shift+G | Ctrl+Shift+F9, обе проекции сменили Ghost на Wireframe |

В другом профиле назначения записали в штатном меню на слоте `SAQ_K_UI_01`. После перезапуска на `SAQ_BASE_01` F2 выбирала A и B, F3 перемещала только B, F5 скрывала и возвращала оба плана, F9 меняла вид с Ghost на Wireframe, F4 удаляла B. Пять прежних сочетаний оставили планы и выбор B без изменений. [Кадр новых назначений](../../evidence/K02-keybindings-rebound.jpg)

При проверке прежних сочетаний SaveCheck закрывал штатный интерфейс игры и восстанавливал предпросмотр перед переносом. В профиле с сочетаниями Ctrl+Shift при вводе в чат и при открытом списке настроек клавиша Ctrl+Shift+F4 оставила оба GUID и позы. После штатного возврата в игру SaveCheck подтвердил обе записи ещё раз.

```text
actions=defaults input=Ctrl+Shift+G views=2 Ghost->Wireframe
pass=1 five plan actions
pass=1 saved five assignments for restart
old_input=Ctrl+Shift+M inactive=1
actions=custom input=Ctrl+Shift+F9 views=2 Ghost->Wireframe
pass=1 five plan actions
actions=safety input=Ctrl+Shift+F4 chat=1 plans=2 unchanged=1
visible_options=mOptionsList
actions=safety input=Ctrl+Shift+F4 options=1 plans=2 unchanged=1
pass=1 chat and options preserve both GUIDs and poses
```
