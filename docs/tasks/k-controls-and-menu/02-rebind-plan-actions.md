# K02. Перенести остальные пять действий в настройки

**Зависимость** — [K01](01-rebind-plan-placement.md). **Цель** — игрок переназначает каждое из шести существующих действий Shadow Architect через одну группу настроек.

## Работа

По образцу «Разместить план» добавьте пять действий со стабильными идентификаторами. Подключите существующие обработчики, сохранив их исходные назначения для чистого профиля. Уберите соответствующие прямые подписки в `BindControls`. [Обработчики и старые привязки](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Исходная раскладка](../../../README.md#управление)

| Действие | Проверяемый результат одного нажатия |
|---|---|
| Выбрать следующий план | При двух планах выбранный GUID сменился с A на B. |
| Переместить выбранный план | С активным предпросмотром поза B совпала с его позой, A остался на месте. |
| Удалить выбранный план | В конце сценария удалён B, остался A. |
| Скрыть/показать планы | Одно нажатие скрывает оба плана, повторное возвращает их. |
| Сменить вид планов | Одно нажатие переводит оба плана ровно на одну позицию в цикле V03. |

## Независимая проверка

- [ ] В чистом профиле видны шесть разных строк группы. Разместите два плана. Проверьте исходные клавиши по таблице, удаление выполните последним.
- [ ] Через меню назначьте пяти действиям разные свободные клавиши и перезапустите игру. На двух планах повторите таблицу новыми клавишами. Для каждой прежней клавиши проверьте, что она больше не вызывает соответствующее действие мода.
- [ ] С открытым чатом и в настройках нажмите новую клавишу удаления при выбранном плане. После закрытия интерфейса оба GUID на месте.

Передайте таблицу прежних и новых клавиш с результатом каждого действия и кадр шести строк в настройках.
