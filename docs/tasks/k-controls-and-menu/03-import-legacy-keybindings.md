# K03. Однократно перенести назначения из Game.ini

**Зависимость** — [K02](02-rebind-plan-actions.md). **Цель** — после обновления пользователь сохраняет свою раскладку и дальше управляет ею из игры.

## Работа

Используйте старые свойства `Place/Select/Move/Delete/Visibility/View` с суффиксами `Key` и `Chord`. Соблюдайте прежний приоритет валидного полного сочетания над `Key` и исходные модификаторы каждого действия. Импортируйте явно заданные значения в настройки соответствующего локального игрока. Сохраните назначения, сделанные в новом меню, включая осознанное снятие клавиши. Импорт должен переживать повторный запуск и штатный сброс раскладки. [Исходный формат и примеры](../../../README.md#переход-со-старой-версии) · [Код миграции](../../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowKeybindings.cpp)

## Независимая проверка

- [x] Обновите копию старого профиля с `PlaceKey=F7`, `PlaceChord=(Key=F8,bAlt=True)` и `SelectKey=F5`. В меню и в мире размещение работает по Alt+F8, выбор — по Ctrl+Shift+F5. Остальные четыре строки имеют исходные значения.
- [x] Назначьте размещению свободную клавишу в игре и снимите назначение выбора. Оставьте старый блок на диске. После двух запусков видны и действуют оба решения игрока. Сбросьте раскладку штатной кнопкой и вновь запустите игру — старый блок повторно не применяется.
- [x] На чистом профиле без старой секции доступны все шесть исходных назначений. На отдельной копии внесите некорректную клавишу рядом с валидной настройкой другого действия. Клиент загружается, валидное назначение переносится, для ошибочного остаётся работоспособное исходное значение.

Передайте минимальный входной фрагмент INI, ожидаемые и фактические назначения после каждого запуска. Обновите инструкцию по переходу для пользователей старой версии.

## Результаты проверки

23 ноября 2026 года. Ревизия `f8d5818` с изменениями K, Satisfactory Steam `rel-main-1.2.6` CL `520140`, SML `3.12.1`, Shadow Architect `0.1.2`. SHA-256 DLL из ZIP и из отдельной установки `d7655aa1399261a6335abf947a30c7d161b265e0f07b496f94593471255c5599`. Входной слот `SAQ_BASE_01`, выходной слот не создан. SaveCheck читал назначения у локального игрока и использовал штатные функции игры для переназначения, снятия клавиши и сброса. Старый блок восстанавливали перед перезапусками тестового профиля.

```ini
[/Script/ShadowArchitect.ShadowPlanSubsystem]
PlaceKey=F7
PlaceChord=(Key=F8,bAlt=True)
SelectKey=F5
```

- Чистый профиль загрузил шесть исходных назначений. Ожидались и получены F7, Ctrl+Shift+J, Ctrl+Shift+M, Ctrl+Shift+K, Ctrl+Shift+V, Ctrl+Shift+G.
- Первый запуск со старым блоком перенёс два назначения. Ожидались и получены Alt+F8 для размещения и Ctrl+Shift+F5 для выбора. Остальные четыре действия сохранили исходные значения.
- На отдельном профиле задали `PlaceKey=NotAKey`, `PlaceChord=(Key=AnotherInvalidKey,bAlt=True)` и валидное `SelectKey=F5`. Ожидались и получены F7 для размещения и Ctrl+Shift+F5 для выбора.
- После штатного переназначения на Ctrl+Alt+F10 и снятия клавиши выбора два запуска с прежним INI дали Ctrl+Alt+F10 и пустое назначение. Те же значения сохранились в отдельном профиле с заранее записанной новой раскладкой при первом импорте. После снятия обеих клавиш следующий запуск загрузил оба пустых назначения.
- Штатный сброс вернул F7 и Ctrl+Shift+J. Повторная загрузка с прежним блоком INI сохранила все шесть исходных назначений.
- Старые `SelectKey=M` и `MoveKey=J` поменяли местами два сочетания. В первом запуске и после перезапуска выбор был назначен на Ctrl+Shift+M, перенос на Ctrl+Shift+J.
- Для `PlaceChord=(Key=F8,bCmd=True)` оба запуска показали `Left Cmd + F8` в подсказке. SaveCheck подтвердил активную привязку клавиши Windows и связанный с ней триггер размещения в Enhanced Input. После сброса и перезапуска отображалось F7.

```text
Imported 2 legacy bindings.
binding=ShadowArchitect.Place actual=Alt+F8 expected=Alt+F8 match=1
binding=ShadowArchitect.Select actual=Ctrl+Shift+F5 expected=Ctrl+Shift+F5 match=1
binding=ShadowArchitect.Place actual=Ctrl+Alt+F10 expected=Ctrl+Alt+F10 match=1
binding=ShadowArchitect.Select actual=unbound expected=unbound match=1
pass=1 scenario=reset-check
physical_command_mapping=1 placement_chord=1
```

В игровом прогоне с тем же минимальным INI два нажатия Ctrl+Shift+F5 последовательно выбрали GUID `396486414CD79819B9C065B066EE5520` и `6E4E9A954896A9D95977ACB5FA91E0E4`. Alt+F8 с активным предпросмотром добавила один план `FC24665849127CAD3E0B38A090F95772`, число планов выросло с 2 до 3. Строки мигрированного профиля прочитаны через штатный API назначений игры.
