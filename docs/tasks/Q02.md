# Q02. Перезагрузить планы без исходников под прежними именами

**Когда выполнять** — После изменений захвата, поиска источника или восстановления.

## Цель

Удалить один исходник и переименовать другой в тестовой библиотеке. Оба размещения должны пережить полный перезапуск. Для действий «Стоимость» и «Построить» проверить заявленное поведение R02 и B02, когда эти функции уже доступны.

## С чего начать

Исходное условие — тестовый мир с двумя уже размещёнными разными Blueprint A и B, доступными в отдельной библиотеке. В базовом опыте обе проекции пережили изменение библиотеки. [Исходник SaveCheck](../../tests/compatibility/SaveCheck/Source/SaveCheck/Private/SaveCheck.cpp) · [Протокол совместимости и запуск SaveCheck](../save-compatibility.md) · [Захват геометрии](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp)

## Работа

1. При обоих источниках запишите контрольные GUID, состав, позы, число видимых акторов и список Blueprint, которые перечисляет игра.
2. На копии библиотеки удалите файлы A и переименуйте пару файлов B. Перезапустите клиент и загрузите прежний слот с этой библиотекой. Сверьте перечисленные игрой имена перед оценкой результата.

## Независимая проверка

- [ ] Старые имена отсутствуют, в библиотеке видно новое имя B. Оба размещения сохранили GUID, состав и позу, в мире восстановлены два видимых актора.
- [ ] Если реализованы R02 и B02, отдельно проверьте цену снимка и решение о строительстве для каждой цели. Результаты сравните с правилами этих задач. Наличие проекции само по себе не доказывает доступность строительства.

## Что передать проверяющему

Приложите две выборки библиотеки и данных мира с обозначением A/B. Выполняйте операции с файлами только на одноразовой копии.
