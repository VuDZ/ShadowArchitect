# Q03. Пересохранить копию мира без мода и включить его снова

**Когда выполнять** — Перед выпуском.

## Цель

Из отдельного слота с двумя планами сохранить мир с отключённым модом в новый слот и включить мод. Проверить число планов в обоих слотах. В 0.1.1 ожидаются 2 в исходном и 0 в новом. Зафиксировать фактическое поведение и сверить с предупреждением в README.

## С чего начать

В 0.1.1 проверено, что пересохранение без Shadow Architect удаляет планы из нового слота. Цель регрессии — установить фактическое поведение выпуска и проверить предупреждение игроку. [Исходник SaveCheck](../../../tests/compatibility/SaveCheck/Source/SaveCheck/Private/SaveCheck.cpp) · [Протокол совместимости и запуск SaveCheck](../../save-compatibility.md) · [Сборка и управление](../../../README.md)

## Работа

1. Подготовьте заведомо отдельный слот A с двумя планами. Завершите клиент, отключите только Shadow Architect, откройте копию A и запишите новый слот B. Подтвердите отключение мода и успешную запись.
2. Завершите клиент и включите мод. Откройте B, затем отдельно A после нового запуска. В каждом случае запишите фактически загруженный слот, версию, число записей и видимых акторов.

## Независимая проверка

- [ ] Для 0.1.1 ожидаются A = 2 и B = 0 после включения. В процессе без мода ожидаются ноль подсистем Shadow Architect и ноль проекций. Одной проверки пустого мира до пересохранения недостаточно.
- [ ] Сравните результат с предупреждением в README. Отметьте расхождение, если новый выпуск изменил поведение. Сверьте контрольную сумму исходного слота A до и после.

## Что передать проверяющему

Приложите результаты трёх переходов, признак успешной записи B и сохранности A. Для запуска тестового модуля используйте команды из протокола совместимости.
