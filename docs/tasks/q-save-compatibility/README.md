# Совместимость сохранений

| Задача | Когда проверять |
|---|---|
| [Q01. Проверить чтение схемы предшествующего релиза](01-load-older-save.md) | При первом изменении формата сохранения и перед выпуском с таким изменением |
| [Q02. Перезагрузить планы без исходников под прежними именами](02-rename-or-remove-blueprint.md) | После изменений захвата, поиска источника или восстановления |
| [Q03. Пересохранить копию мира без мода и включить его снова](03-resave-with-mod-disabled.md) | Перед выпуском |
