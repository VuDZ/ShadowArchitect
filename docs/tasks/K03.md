# K03. Однократно перенести назначения из Game.ini

**Зависимость** — [K02](K02.md). **Цель** — после обновления пользователь сохраняет свою раскладку и дальше управляет ею из игры.

## Работа

Используйте старые свойства `Place/Select/Move/Delete/Visibility/View` с суффиксами `Key` и `Chord`. Соблюдайте прежний приоритет валидного полного сочетания над `Key` и исходные модификаторы каждого действия. Импортируйте явно заданные значения в настройки соответствующего локального игрока. Сохраните назначения, сделанные в новом меню, включая осознанное снятие клавиши. Импорт должен переживать повторный запуск и штатный сброс раскладки. [Исходный формат и примеры](../../README.md#управление) · [Свойства подсистемы](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.h)

## Независимая проверка

- [ ] Обновите копию старого профиля с `PlaceKey=F7`, `PlaceChord=(Key=F8,bAlt=True)` и `SelectKey=F5`. В меню и в мире размещение работает по Alt+F8, выбор — по Ctrl+Shift+F5. Остальные четыре строки имеют исходные значения.
- [ ] Назначьте размещению свободную клавишу в игре и снимите назначение выбора. Оставьте старый блок на диске. После двух запусков видны и действуют оба решения игрока. Сбросьте раскладку штатной кнопкой и вновь запустите игру — старый блок повторно не применяется.
- [ ] На чистом профиле без старой секции доступны все шесть исходных назначений. На отдельной копии внесите некорректную клавишу рядом с валидной настройкой другого действия. Клиент загружается, валидное назначение переносится, для ошибочного остаётся работоспособное исходное значение.

Передайте минимальный входной фрагмент INI, ожидаемые и фактические назначения после каждого запуска. Обновите инструкцию по переходу для пользователей старой версии.
