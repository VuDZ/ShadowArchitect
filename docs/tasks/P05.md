# P05. Обработать двухшаговое размещение ленты

**Зависимости** — [P04](P04.md).

## Цель

Обработать многошаговое размещение на примере ленты.

## С чего начать

Лента получает форму после выбора обоих концов. Текущий захват может заменять сплайны габаритами. Сверьте протокол P01 и возможности представления P04 перед изменением поведения. [Захват геометрии](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowCapture.cpp) · [Управление планами](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Рендер проекции](../../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowProjection.cpp)

## Работа

1. Отследите промежуточный, отменённый и подтверждённый шаги. Создавайте запись только тогда, когда известны оба конца и выбранный путь.
2. Попробуйте прямую и изогнутую ленту. Если форму нельзя воспроизвести из сохранённых данных, сделайте этот случай явно неподдержанным с объяснением при попытке размещения.

## Независимая проверка

- [ ] Поставьте первую точку и отмените. Число планов, реальных лент и ресурсы прежние. Начните заново и укажите оба конца.
- [ ] Для поддержанной формы появляется ровно одна проекция с теми же концами и изгибом после загрузки. Для неподдержанной формы есть сообщение и ноль новых записей. Реальных лент и расхода нет в обоих случаях.

## Что передать проверяющему

Запишите результаты отдельно для прямой и изогнутой ленты. Параллелепипед сам по себе не подтверждает воспроизведение изгиба.
