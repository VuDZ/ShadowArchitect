# Проверка Shadow Architect

**Состояние на 23.11.2026.** Офлайн-проверки выполнены. Редакторная и Steam Shipping сборки прошли. Приёмка A–E открыта.

| Проверка | Результат |

| Офлайн-чтение Blueprint | Для 25 из 25 файлов прочитаны таблицы до точной границы записей. Получены трансформации 590 акторов, 32 разных класса. Три файла потребовали распаковки второго блока. |

## Подготовка игрового прогона

Используйте новый одиночный мир либо отдельную копию тестового сохранения. Начните с профиля SMM, в котором активны SML и Shadow Architect. Затем повторите A, C и E с пользовательским набором модов, включая Smart! и InfiniteNudge. Для D создайте одноразовый Blueprint в тестовой библиотеке. Пользовательский оригинал должен остаться доступным.

Перед запуском зафиксируйте CL, версию SML, версию DLL и список модов. При загрузке проверьте запись `Ready`. Для каждого размещения запишите из чата имя, GUID и количество объектов. Для контроля координат выберите план клавишей выбора и сохраните его сообщение из журнала. Снимите экран до и после закрытия Build Gun.

Поверните и сдвиньте preview через Nudge, нажмите F7, затем закройте Build Gun. Число объектов совпадает, позиции, габариты и повороты узнаваемы. Инвентарь и количество настоящих зданий прежние. ## Отказы для первого прогона

- Нажмите Place без Build Gun, с обычным фундаментом и сразу после смены Blueprint. При неготовом preview ожидается отказ с сообщением и без частичного плана. Нажмите повторно после появления геометрии.
- Сравните число зданий тестового чертежа и корней. Если число отличается, запишите класс отсутствующего объекта, положение pivot и режим Nudge. Отдельно проверьте модовый станок и нелинейную ленту. Невидимую или неверно ориентированную часть считайте дефектом A.
- При наличии одноразового тестового мода с собственным мешем сохраните план, затем загрузите копию мира без поставщика меша. У данного здания ожидается proxy прежних размеров. Оригинальный Blueprint в этом тесте не нужен.
- Разместите и удалите несколько планов, выйдите в меню, затем загрузите другой тестовый мир. Там не должно быть визуальных акторов или выбора из предыдущего мира. Отметьте задержку при создании и загрузке крупных планов и сообщения `LogShadowArchitect`.

Статус MVP меняется после успешной сборки, установки и наблюдения всех пяти сценариев в Steam-клиенте. Положительный результат Python-пробы подтверждает только дисковую часть исследования.
