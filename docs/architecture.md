# Архитектура Shadow Architect

Одна планировка принадлежит одному игровому миру. Просмотр и редактирование работают по сохранённому снимку. При захвате мод записывает отпечаток загруженного Blueprint. Строительство требует подтверждённого источника в библиотеке текущего мира. Выбор, поворот, Nudge и подтверждение настоящего строительства остаются у Build Gun.

```text
Активный AFGBlueprintHologram
    │ Place Shadow
    ▼
CaptureBlueprint ──► FShadowPlacement ──► AShadowPlanSubsystem.Plans ──► игровой save
                           │                       │ загрузка
                           ▼                       ▼
                     AShadowProjection ◄─────── Restore
                           │
                           └── USceneComponent + UStaticMeshComponent
```

## Снимок и координаты

| Данные | Семантика |
|---|---|
| FShadowPlacement | Версия 1, новый GUID для каждого размещения, исходное имя BlueprintId, мировой Transform и массив Parts. BlueprintSourceProof хранит отпечаток точных байтов загруженного источника, если чтение подтверждено. Исходное имя служит подписью в чате. |
| FShadowPart | Одна запись на визуальный корень здания. Путь класса хранится строкой. InPlan задаёт положение корня относительно якоря preview. Центр и размеры габаритов выражены в локальной системе здания, в см. |
| FShadowMesh | Мягкая ссылка на статический меш и его transform относительно корня здания. У экземпляров ISM свои трансформации. |
| AShadowPlanSubsystem | Массив снимков и единый флаг видимости имеют SaveGame. Выбранный GUID, привязки ввода, карта слабых ссылок на визуальные акторы и загруженный материал относятся к текущему сеансу. |

В порядке умножения Unreal мировой transform меша равен `Mesh.InPart * Part.InPlan * Plan.Transform`. Геометрия с несколькими материалами получает материал проекции во всех слотах. Если отсутствует хотя бы один сохранённый меш, весь объект отображается одним proxy по сохранённым габаритам. Ссылка на класс здания и файл Blueprint при загрузке не разрешаются. ## Жизненный цикл

1. **Создание мира.** SML обнаруживает нативный `UShadowWorldModule` и регистрирует `AShadowPlanSubsystem` с политикой SpawnOnServer. В одиночной игре ввод привязывается к локальному контроллеру. Если он ещё инициализируется, подсистема повторяет привязку по таймеру. Репликация проекций не реализована.
2. **Place.** На игровом потоке мод снимает данные с текущего preview. До успешного создания визуального актора снимок остаётся локальным. Невалидный объект или неполное сопоставление с доступным списком временного мира отменяет операцию целиком. Нажатие снова создаёт самостоятельный GUID.
3. **Управление.** Перемещение меняет один мировой transform актора и его записи. Видимость меняет флаг и видимость существующих акторов. Выбор циклический по порядку добавления, поэтому проекциям не нужны коллизии для попадания луча. Удаление освобождает визуальный актор и убирает одну запись.
4. **Сохранение и загрузка.** `IFGSaveInterface::ShouldSave_Implementation` включает подсистему в игровой save. Мир восстанавливает SaveGame-поля. `BeginPlay` создаёт визуализацию после ранней загрузки. `PostLoadGame_Implementation` повторяет восстановление, если актор уже начал игру. Предыдущее transient-представление очищается при каждом восстановлении. Неизвестная версия схемы или недоступный материал регистрируются в журнале, загрузка остальных записей продолжается. Поддержка чтения данных из будущих версий не гарантируется. [Правила сохранения Satisfactory](https://docs.ficsit.app/satisfactory-modding/latest/Development/Satisfactory/Savegame.html)
5. **Завершение мира.** Подсистема снимает ввод, останавливает таймер и уничтожает визуальные акторы вместе с их компонентами. У рендера нет Tick. Загрузка мешей синхронная при создании и восстановлении. Большие планы могут дать задержку в эти моменты. [Управление миром](../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowPlan.cpp) · [Рендер](../src/ShadowArchitect/Source/ShadowArchitect/Private/ShadowProjection.cpp)

## Где проходят границы

`AShadowProjection` — transient AActor с подвижным корнем. Компоненты получают NoCollision, выключенные overlap, навигацию и отбрасывание теней. Мод не вызывает строительство, не копирует компоненты производства и регистрации в сетях, не редактирует исходные файлы. Сохранение выполняет сама игра. Реальное поведение физики, материалов, загрузки и ввода проверяется тестами A–E.

Офлайн-эксперимент использует Python и стандартную библиотеку. Он запускается отдельно и не входит в плагин или зависимости игрока.
