# Игровые проверки для агентов

Начните с карточки задачи и её раздела «Независимая проверка». Для проверок сохранения и состояния мира в этом проекте можно запустить реальный Steam-клиент Satisfactory в фоне. Используйте тестовый плагин `SaveCheck`, когда его вывод отвечает на вопрос карточки. [Индекс задач](docs/work-plan.md) · [Подготовка, запуск и разбор результата](docs/background-testing.md)

- **Планы и сохранения.** Для Q01–Q03 доступны фактическая версия мода, состав библиотеки Blueprint, контрольные суммы записей, число проекций и результат штатной записи слота. Работайте на отдельной копии мира и библиотеки, когда пользовательская игра закрыта. [Проверенные сценарии](docs/save-compatibility.md)
- **Изображение и ввод.** Читаемость Wireframe и положение экранной метки оценивайте по кадру. Для физической клавиши, особенно через RDP, фиксируйте действие игрока и результат обработчика. Для позы, расхода ресурсов или реального строительства нужны замеры, указанные в карточке; текущий `SaveCheck` этих величин отдельно не выводит.
- **Отчёт.** Укажите ID задачи, ревизию, версии игры и мода, входной и выходной тестовые слоты, ожидаемый и наблюдаемый результат. Приложите относящиеся к критерию строки журнала или кадр. Если проверена только часть сценария, перечислите открытые пункты.
